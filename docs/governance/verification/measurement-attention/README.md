## Reviewed W-93 operator plan

The preview→review→per-device apply→preserved rollback sequence fits framework 14.2 **as a bounded type/capability repair**, after identity/source reconciliation and converter evidence; it is not the complete W-101 identity migration. Do not reinterpret “implement #244” as approval of a still-unseen live diff.

Before Nate operates:

1. Record exact running artifact/digest and source-qualified physical identity, current friendly-name aliases, location, model, firmware, supported converter/exposes and acquisition evidence. Separate stale original parents from the active device; ambiguous identity stops the plan. S61 starts only if it actually has a changed type/capability diff; no forced mutation of an already-correct row.
2. Authenticated administrator preview must list current/proposed values and selected fields. Save the preview and a before snapshot of descriptor, lifecycle, room/parent references, service bindings and workflow links. Candidate or previously-exposed rows are not accepted/enabled by this endpoint; resolve enrollment separately with Nate.
3. Review each exact device/field diff with Nate and obtain explicit go. Re-preview immediately before apply; stop if inference, identity or current fields changed. API does not bind apply to a preview token or compare-and-swap version, so quiesce competing configuration writers and serialize these operations.
4. Apply one approved device only; securely save its original returned rollback object with device ID, selected fields, timestamp and artifact version. A no-op apply is not a repair. Retain the original changed-apply object, not a later no-op response. The object itself is not device-bound/signed; the operator must match it to the same device and detect intervening edits before rollback.
5. Read back type/capabilities; assert name/enabled/location/protocol/connection, room/parent references, lifecycle, workflows and historical IDs unchanged. Verify actual reporting and Monitoring card, including sensor vs relay classification, zero vs unavailable and ON/OFF+watts. Collect fresh observations; HA poll success alone is insufficient. No power toggle to test.
6. Abort on mismatch. Roll back only with the matched saved object and after checking no later approved type/capability edits would be overwritten. Recheck the same invariants. Capture operator evidence; process-restart rollback drill stays NOT_RUN until explicitly exercised safely. General release still requires W-106 pilot/rollback/comprehension sign-off.

No live row, ontology threshold, attention styling or load state is changed by this verification package. The remaining broad #244 tasks remain open.
