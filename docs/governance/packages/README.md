# Review packages

A package holds facts or proposals that are not yet canonical and are waiting for a scheduled review. Each package has one backlog row (WSJF-scored like any other item), one file here, and a disposition table. When every item is moved to its canonical home or dropped, the closing PR deletes the file and closes the backlog row.
