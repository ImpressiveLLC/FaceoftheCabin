## Result

Intent accuracy, the failed-fixture set and the critical count were identical across all three runs of every arm. Slot F1 on the 49 rows moved between 0.569 and 0.581, the same range the unchanged base showed in r10 (0.569, 0.569, 0.581), so it is not a candidate effect.

**Reading.** Adding descriptions to the schema changed nothing measurable on either set. This matches the stated hypothesis (not a finding about Ollama's internals, which this round did not inspect) that the schema is converted into a decoding constraint in which descriptions are not shown to the model. E4 is therefore not a candidate and no later round needs it; if field guidance is wanted, it would have to be in the prompt, which is wording and was ruled closed for this tag.

Nobody has reviewed these rows for admission to gold.
